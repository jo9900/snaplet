# Snaplet support

For help with Snaplet, email [adeliaehd85512b@gmail.com](mailto:adeliaehd85512b@gmail.com)
or [open a GitHub issue](https://github.com/jo9900/snaplet/issues).

Include your macOS version and the steps that led to the problem. Do not attach private
screenshots or personal information to public issues.

## Getting started

1. Launch Snaplet and press **⌘⇧2**, or choose **New Screenshot** from its menu bar icon.
2. Allow **Snaplet** in System Settings → Privacy & Security → Screen & System Audio
   Recording (called Screen Recording on some macOS versions). Reopen the app if prompted.
3. Select an area, add annotations, then use **Copy** or **Save**.

Snaplet requires macOS 14 or later. It captures still images and does not record video or audio.
